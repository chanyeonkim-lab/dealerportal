# 딜러 포털 디자인 개선

적용 스킬: `.agents/skills/frontend-design/SKILL.md`.
목표: 호주 딜러의 고객 상담 준비, 계약 검토, EV 교육을 한 작업 공간에서 찾기 쉽게 만든다. 기존 API, 데이터베이스, 계약 저장과 교육·퀴즈 동작은 유지한다.

## 레퍼런스 우선순위와 현재 방향

사용자 제공 Hyundai → Genesis → Vercel 순서로 적용한다. Hyundai의 navy `#002c5f`, teal `#007fa8`, cyan `#00aad2` 및 사각형 액션이 우선이며, Genesis의 indigo·green 색상과 둥근 카드는 적용하지 않는다. Genesis에서는 여백, 절제된 테두리, 편집적인 위계를 참고한다. Vercel은 사용자가 제공한 글의 타이포그래피·색상·구도 원칙을 참고했으며, `vercel.com/design.md`는 접근 거부로 직접 검증하지 못했다.

- 탐색: 흰색 레일과 navy 활성 메뉴. 낮은 데스크톱 화면에서는 보조 브랜드 문구를 숨겨 주요 탐색 공간을 확보한다.
- 홈: navy 텍스트 영역과 기존 차량 일러스트를 분리한 2열 구성. 모바일에서는 세로로 쌓는다. 일러스트는 실제 모델이나 사양을 주장하지 않는다.
- 제목: 34–48px의 보통 굵기와 짧은 줄 길이. 색상으로 단어 하나만 강조하지 않는다.
- 표·폼·교육·어시스턴트: 읽기 쉬운 보조 텍스트, 평면 패널과 사각 액션, 브랜드 색상의 포커스. 아바타와 상태 점은 원형을 유지한다.
- Hyundai 폰트의 배포 파일과 사용 허가가 제공되지 않아 기존 자체 제공 Manrope / Public Sans를 유지한다. 외부 폰트 요청은 없다.
- 계약 업로드 보조 문구는 기존 접근성 검사에서 발견한 대비 문제를 수정한다.

## 디자인 토큰

- Hyundai navy `#002C5F`: 주요 행동과 브랜드.
- White `#FFFFFF`: 탐색 메뉴와 패널; 활성 메뉴는 Hyundai navy.
- Ink `#171B20`: 제목과 중요한 데이터.
- Neutral `#FAFAFA`: 작업 배경. Border `#E1E4E7`: 표와 패널 경계.
- Sky `#B9DCE7`: 차량 일러스트의 빛과 선택 보조색.
- Teal `#007FA8`: 키보드 포커스와 강조. Cyan `#00AAD2`: 픽셀 모티프.
- Manrope: 제목과 숫자. Public Sans: 본문과 폼. npm 폰트 패키지를 통해 자체 제공하고 런타임 외부 폰트 요청을 하지 않는다.

## 배치 검토

초기안의 동일한 카드 나열을 줄이고, 홈의 네 지표를 하나의 요약 띠로 묶었다. 차량 일러스트는 실제 차종 사양을 주장하지 않는 독립 데모 그림이며 코드로 작성한 SVG다. 고객 목록에는 고객·차량·진행 단계·금액·다음 행동을 같은 행에 배치했다. 넓은 화면에서는 교육과 어시스턴트를 옆에, 작은 화면에서는 아래에 배치한다.

```text
데스크톱
[탐색] [현재 위치 / 시장]
       [페이지 제목                     새 계약]
       [상담→계약 안내     차량 일러스트]
       [기회 수 | 파이프라인 | 계약 | 교육]
       [고객 목록]              [교육 / 도움]

계약 검토
[Opportunity 선택 / 편집 필드] [예제 참고 문서]
[검토 확인]                   [경고 / 추출 근거]
[사람 검토 안내                         저장]
```

## 세부 결정

- 실제 업로드 원문이 보관되는 것처럼 표현하지 않는다. 샘플 옆 문서는 **Prepared example reference**로 표시한다. 실제 AI 결과는 추출 근거만 표시하며 원문 검증 기능을 새로 완성했다고 주장하지 않는다.
- Opportunity를 바꾸거나 추출 필드를 수정하면 검토 확인을 해제한다.
- 검색 결과가 없을 때 결과 없음, 검색 수정 안내와 필터 초기화 동작을 제공한다.
- 모바일은 메뉴 버튼으로 탐색을 열고, 대화상자와 메뉴에서 키보드 포커스를 관리한다. Escape로 닫고 기존 버튼으로 포커스를 돌린다.
- 작은 화면의 입력 글자는 16px로 설정해 모바일 확대를 줄인다. 넓은 표는 표 내부에서만 가로 스크롤한다.
- reduced-motion 설정을 존중한다.
- 자동 접근성 점검에서 발견한 회색 설명·단계 표시·예제 문서의 낮은 대비를 어둡게 조정했다. 자동 검사 통과는 모든 접근성을 보장하지 않는다.

## 범위

디자인 변경은 실제 OpenAI API 호출을 필요로 하지 않는다. 공개 정적 미리보기는 기존대로 예제만 사용한다. 실제 API 키는 별도 선택 설정이며 이 작업에서 생성하거나 사용하지 않는다. 이 디자인 변경은 Sites 게시 완료를 의미하지 않는다.
